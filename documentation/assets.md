# Static Assets (`public/`)

All assets copied from the Django project. Images are generally large (1-2MB) — consider optimization if adding new ones.

| Path | Contents |
|------|----------|
| `public/videos/` | `hero-bg.mp4` (6.5MB) — hero section video background |
| `public/images/sponsors/` | Partner/funder logos: Allan Gray, BCL, Click, DGMT, DoE EC, Funda Wande, Gates Foundation, Masi, TLT, TeampAct |

| `public/images/results/` | Results/data visualizations |
