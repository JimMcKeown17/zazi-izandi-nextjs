## Design changes

Right now the page is informative, but visually it feels a little busy because every card is competing for attention with:

strong background tints
colored borders
many pills/badges
several boxed metrics inside each card
lots of different accent colors at once

That makes it feel more “dashboard-heavy” than “sleek product.”

What I would change first
1. Make the cards mostly white

Instead of tinting the whole card red/yellow/green, use:

white or very light neutral card background
subtle gray border
one small status chip or a thin left border / top accent for rating

So:

On Track = green chip only
Needs Attention = amber chip only
Low Dosage = red chip only

This one change alone would make the page feel much more premium.

2. Reduce the number of visual containers inside each card

Right now each metric sits in its own rounded box. That creates a lot of mini-panels.

A cleaner approach:

keep 1 primary metric row
show the rest as lighter secondary stats
reserve outlined boxes only for the single most important metric

For example:

School Name
School type • 2 EAs • 53 children

2.4
Dosage sessions/group/week

Avg/day worked 3.3
Sessions this week 0

That is much more product-like.

3. Let's have just one one hero metric per card

Dosage

Make that number big and central.
Everything else becomes supporting context.

Apple/Google UIs usually have a very obvious focal point, not 6 equally loud elements.

4. Calm the typography

Use a more restrained type system:

School name: strong but slightly smaller than now
Metadata: small, muted gray
Main metric: large and bold
Secondary stats: medium weight
Flags: small and quiet

A clean hierarchy might be:

24–28px bold school title
13–14px muted metadata
32–40px for primary metric
14–16px for secondary stats

Also reduce the number of bold labels. Too many bold items makes nothing feel special.

5. Use color only for meaning, not decoration

Right now color is everywhere. A sleeker system would use color in only 3 places:

status chip
key metric when problematic
alert indicators

Everything else should be neutral gray/black.

That gives the colored elements real power.

6. Increase whitespace and alignment discipline

Your page would feel much more professional if every card followed a very strict internal rhythm:

24px outer padding
16px vertical spacing between sections
aligned baselines for numbers
identical heights for metric rows
consistent chip sizing

Google/Apple interfaces often feel premium because the spacing is incredibly disciplined.
